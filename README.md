# Fever

An open-source digital audio workstation (DAW) that runs in the browser, with all of its instruments and effects written from scratch.

> **Status:** early planning. Nothing is playable yet.

## Architecture (planned)

- **Audio engine:** Rust compiled to WebAssembly, running inside a Web Audio `AudioWorklet`
- **UI:** JavaScript/TypeScript in the browser
